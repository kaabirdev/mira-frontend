    Quick start

    Send your first notification

    One REST call fans out to every subscriber. Mira queues each delivery, retries failures and records the provider response.

    1. 1Create a secret key with notifications:send
    2. 2Register subscribers through the publishable key
    3. 3POST to /v1/notifications
    Read the docs Manage API keys
    POST /v1/notifications 
    curl https://api.lazytown.dev/v1/notifications \
  -H "Authorization: Bearer mira_sk_live_…f9a2" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: launch-2026-11-10" \
  -d '{
    "title": "New dashboard is live",
    "body": "Charts and delivery logs are here.",
    "url": "https://acme.dev/changelog",
    "target": { "type": "segment", "id": "seg_active_web" }
  }'

    Secret keys are hashed with HMAC-SHA256 and never stored in plaintext.
