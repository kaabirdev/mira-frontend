Isolation by default

API keys are scoped to a single project. A request authenticated with one project’s key can never read another project’s subscribers, deliveries or usage. Ownership is verified on every protected operation.

Test before you ship

Test-environment keys use mira_sk_test_ prefixes and never touch live provider credentials. Switch environments from the project menu without changing code.
