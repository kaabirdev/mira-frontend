Verify a signature

PHP 8.2

$payload = file_get_contents('php://input');
$timestamp = $_SERVER['HTTP_X_MIRA_TIMESTAMP'];
$signature = $_SERVER['HTTP_X_MIRA_SIGNATURE'];

$expected = hash_hmac(
    'sha256',
    $timestamp . '.' . $payload,
    $signingSecret
);

if (! hash_equals($expected, $signature)) {
    http_response_code(401);
    exit;
}

Reject timestamps older than five minutes. Retries use exponential backoff and preserve the original event ID.
