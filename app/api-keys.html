Authentication guide

Secret keys stay server-side

Used as Authorization: Bearer mira_sk_live_…. They are hashed with HMAC-SHA256 and a server-side pepper — never stored as plaintext.

Publishable keys are public by design

Limited to subscriber registration. A publishable key can never send notifications or read sensitive project data.
